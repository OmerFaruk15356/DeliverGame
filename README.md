# Delivery Driver

A 2D top-down driving game where you pick up packages and deliver them to their destination. It is the "Delivery Driver" project from GameDev.tv's Complete C# Unity 2D course, followed along as a learning exercise.

## Opening the project

Open the project folder in Unity 2021.3.16f1 and load `Assets/Scenes/SampleScene.unity`.

## Controls

- Up and down arrows, or W and S — drive forward and back
- Left and right arrows, or A and D — steer
